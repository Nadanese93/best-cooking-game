Run the busiest street noodle cart in town. A 150-second shift: order tickets
arrive on the board with draining patience bars. Cook noodles in the pot and
click it in the green zone for a perfect batch (too long and they burn), chop
chicken and greens on the board, build each bowl to match its ticket exactly,
and serve before the customer walks out. Fast serves earn speed tips, and
three clean serves in a row build a combo multiplier up to x3. Earn 120 coins
before the shift ends to win — 3 failed orders ends the run.

Play it: serve `game/` with any static server and open `index.html`.
Mouse is primary; keys 1–7 pick stations, Space serves, R restarts, M mutes.
Sounds are synthesized with WebAudio — no audio files, no network.
